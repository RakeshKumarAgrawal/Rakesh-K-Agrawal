# Security Policy

## Overview

Thank you for helping maintain the security and integrity of this repository.

This repository contains personal professional materials, research references, technical documentation, and public portfolio resources maintained by Rakesh Kumar Agrawal.

Security issues and responsible disclosures are appreciated to help keep this repository safe and reliable.

---

## Supported Versions

The latest version available in the `main` branch is actively maintained.

| Version | Supported |
|---------|-----------|
| Main branch | ✅ Yes |
| Latest commit | ✅ Yes |
| Older versions | ⚠️ Limited |

Security fixes and updates will be applied to the latest maintained version.

---

## Reporting a Vulnerability

Please do not publicly disclose security issues through GitHub Issues.

If you identify a security vulnerability, please report it privately through:

- GitHub Security Advisories ("Report a vulnerability")
- Email: rkagrawal@ieee.org

Please include:

- Description of the issue
- Affected file or resource
- Steps to reproduce
- Potential impact
- Recommended fix (if available)

---

## Response Process

Security reports will be reviewed responsibly.

Expected response timeline:

- Initial acknowledgment within 7 days
- Investigation of the reported issue
- Resolution or mitigation where applicable

---

## Scope

This policy applies to:

- Repository files
- Documentation
- Images and assets
- Configuration files
- Public profile materials
- Linked references

---

## Security and Privacy Considerations

Please report concerns involving:

- Accidental exposure of sensitive information
- Unauthorized changes to repository content
- Malicious modifications
- Broken links or unsafe external references
- Security issues affecting visitors

---

## Responsible Disclosure

Security researchers and contributors are requested to:

- Avoid public disclosure before review
- Provide sufficient details for investigation
- Allow reasonable time for remediation

Responsible reporting helps maintain the quality, trust, and professionalism of this repository.
